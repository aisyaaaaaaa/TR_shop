# Bakpao Gemoy 🛍️

## Deskripsi
Bakpao Gemoy merupakan proyek website toko online yang dirancang untuk menampilkan produk, memberikan informasi katalog, serta menyediakan tampilan halaman belanja secara digital.

## Fitur
- Halaman utama dan katalog produk.
- Halaman login dan registrasi.
- Wishlist produk.
- Halaman checkout.
- Tampilan promosi dan diskon.
- Navigasi website yang responsif.

## Teknologi
- HTML
- CSS
- JavaScript
- Bootstrap 5
- jQuery
